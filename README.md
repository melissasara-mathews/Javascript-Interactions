# JavaScript Interactions

A small project created to practise basic JavaScript concepts and understand how JavaScript can be used to add interactivity to webpages.

## What I Did

* Connected an external JavaScript file to an HTML webpage
* Selected HTML elements using JavaScript
* Added a button click event using an event listener
* Updated webpage content dynamically
* Practised basic DOM manipulation
* Published the project using GitHub Pages
